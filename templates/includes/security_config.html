Security

An admin key is the public key of the device that administers this node. A random value gives no admin access.

Paste the public key of an admin device: 32 bytes in base64, hex or { 0x.. } form. USERPREFS_USE_ADMIN_KEY_0
Paste the public key of an admin device: 32 bytes in base64, hex or { 0x.. } form. USERPREFS_USE_ADMIN_KEY_1
Paste the public key of an admin device: 32 bytes in base64, hex or { 0x.. } form. USERPREFS_USE_ADMIN_KEY_2
The policy that the device applies to packets from other nodes. USERPREFS_CONFIG_SECURITY_PACKET_SIGNATURE_POLICY
Managed mode is on. The device rejects local config changes. Only admin key 0–2 holders can change it remotely. Without an admin key, nobody can.
Managed mode needs at least one admin key. USERPREFS_CONFIG_SECURITY_IS_MANAGED
