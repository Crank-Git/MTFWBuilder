Mesh Beacon

A mesh beacon is a scheduled broadcast with a message and an offered channel, modem preset and region. Other devices can join the offered mesh.

Accept the mesh beacons of other devices. The firmware default is on. USERPREFS_MESH_BEACON_LISTEN_ENABLED
Broadcast a mesh beacon from this device on a schedule. The firmware default is off. USERPREFS_MESH_BEACON_BROADCAST_ENABLED
The time between two beacon broadcasts. Seconds: 0, or 3,600 to 2,592,000. USERPREFS_MESH_BEACON_INTERVAL_SECS
The text of each beacon broadcast. The firmware keeps the first 60 bytes. USERPREFS_MESH_BEACON_MESSAGE

Offer

The channel, frequency slot, modem preset and region that the beacon offers to the devices that receive it.

The name of the offered channel. USERPREFS_MESH_BEACON_OFFER_CHANNEL_NAME
The PSK of the offered channel: 0, 1, 16 or 32 bytes in base64, hex or { 0x.. } form. USERPREFS_MESH_BEACON_OFFER_CHANNEL_PSK
The offered frequency slot, from 1. Set it only when the mesh uses a slot that is not the default. USERPREFS_MESH_BEACON_OFFER_FREQUENCY_SLOT
The modem preset that the beacon offers. USERPREFS_MESH_BEACON_OFFER_PRESET
The region that the beacon offers. USERPREFS_MESH_BEACON_OFFER_REGION

Broadcast Targets

Each target is one set of radio settings that the device sends a beacon copy on. Without a target, the device sends one beacon on its own modem preset and region, on the primary channel.
