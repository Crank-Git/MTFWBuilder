Network Configuration

The protocols that the device uses on the network. USERPREFS_NETWORK_ENABLED_PROTOCOLS
The device connects to the WiFi network below. USERPREFS_NETWORK_WIFI_ENABLED
The device also uses IPv6 on the network. USERPREFS_NETWORK_IPV6_ENABLED
The name of the WiFi network. USERPREFS_NETWORK_WIFI_SSID
The password of the WiFi network. USERPREFS_NETWORK_WIFI_PSK

MQTT Configuration

The device connects to the MQTT server below. USERPREFS_MQTT_ENABLED
The host name or IP address of the MQTT server. USERPREFS_MQTT_ADDRESS
The first part of the topic of each MQTT message. USERPREFS_MQTT_ROOT_TOPIC
The user name for the MQTT server. USERPREFS_MQTT_USERNAME
The password for the MQTT server. USERPREFS_MQTT_PASSWORD
The device sends packets to MQTT encrypted with the channel PSK. USERPREFS_MQTT_ENCRYPTION_ENABLED
The device connects to the MQTT server with TLS. USERPREFS_MQTT_TLS_ENABLED
